# Fondos editoriales

Esta carpeta contiene los fondos visuales de la web. Para el rediseño inspirado en `CECI-COLORES.jpg`, usar estos nombres finales:

- `bg-hero.webp`
- `bg-conversations.webp`
- `bg-book.webp`
- `bg-author.webp`
- `bg-launches.webp`
- `bg-faq.webp`
- `bg-footer.webp`
- `bg-card-pattern.webp`

Los fondos deben ser suaves, sin texto, sin logos y sin personas generadas. La foto real de Cecilia y la portada real del libro se mantienen como assets separados.

Mientras falte alguno de estos WebP, el CSS debe conservar gradientes y colores de respaldo para que la web no se rompa.
