# Prompts Para Fondos IA

## PROMPT HERO
"Usar la imagen de referencia adjunta como inspiración visual principal. Crear un fondo horizontal 16:9 para la sección principal de una web sobre un libro de comunicación emocional. Estética editorial cálida, papel beige texturizado, forma orgánica crema grande, acuarela turquesa suave en una esquina, hojas finas dibujadas a mano en marrón claro, pequeños puntos decorativos, composición minimalista, mucho espacio vacío para texto, delicado, artesanal, moderno, sin texto, sin personas, sin logos."
